Data handling

Privacy policy

This policy describes Billy Finance, a personal-use application operated by its account owner. It is not a public budgeting service.

Information accessed

With the operator’s authorization, the assistant may access selected Drive file metadata and contents, Sheets cell values, formulas, formatting and category lists. Transaction exports may contain dates, amounts, merchant descriptions, account references and other financial information.

OAuth requests Drive and Sheets access only. The granted scopes are broader than one folder; the assistant is operated within the finance files selected by its owner. No Gmail, Calendar or Contacts access is requested for this integration.

Purpose and control

Information is used to carry out the operator’s requested budget inspection, transaction categorization, duplicate checking, monthly rollover, workbook updates and migration. Uncertain classifications are presented for review. Concrete finance changes require the operator’s approval.

AI processing and other services

The assistant is not an entirely local AI system. Content included in prompts and tool results may be sent to the configured model provider, currently OpenAI, to perform the requested task. Self-hosted file storage does not prevent this transmission. The operator must review the provider’s applicable data-handling settings and terms before sending financial information.

When chat delivery is used, messages and attachments may also be stored by the chosen chat platform, such as Discord or Telegram. Sensitive records should not be posted to public or broadly shared channels.

Billy Finance does not sell Google user data or use it for advertising. Google user data must not be used to train or improve general-purpose AI models. Only service configurations consistent with that restriction should be used.

Billy Finance’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

Workbooks and transaction exports may remain in Google Drive, private self-hosted storage and local working copies. Processing reports and conversation records can contain excerpts. Original cloud files are retained until the operator approves removal following migration checks.

There is no automatic deletion deadline for all records. The operator controls removal of source files, working copies and application history; backups and external services may retain copies under their own settings and policies.

Credentials and access

OAuth tokens and service credentials are retained in protected local files or the operator’s dedicated password vault. They must not be included in public pages, application output or chat messages. Access to the finance storage uses a dedicated restricted account.

Revoke access and delete data

The operator can revoke Billy Finance in their Google Account’s third-party connections settings. Revocation stops future authorized Google access but does not delete existing local copies. To remove those copies, the operator must delete the relevant files, processing history and backups as appropriate, and address any external-service retention separately.

This public website

These static pages contain no financial records, uploads, analytics scripts or application credentials. The hosting provider may process ordinary request information such as IP addresses for website delivery and security.

Contact and changes

For privacy questions or deletion assistance, contact hillbillybot07@gmail.com. Do not send passwords, tokens or financial exports by email. The policy should be updated before material changes to the application’s data handling.

Private personal-use application. This public information site does not provide access to the application or financial records.
