Billy Finance

Billy Finance is a privately operated assistant for managing the operator’s own monthly budget workbooks. It uses Hermes Agent to help review transaction exports, suggest existing budget categories, and maintain monthly plans.

What it does

  • Reads selected Google Drive files and Google Sheets workbooks to understand budget structure and categories.
  • Prepares monthly rollover while preserving planned values and formulas.
  • Checks transaction exports for potential duplicates and flags uncertain categories for review.
  • Writes approved workbook changes and checks imported counts and amounts.
  • Supports migration to the operator’s private, self-hosted storage.

Google access

Authorization requests Drive and Sheets permissions only—not Gmail, Calendar or Contacts. These Google permissions can be account-wide; restriction to the operator’s selected finance files is an application operating rule, not a Google-enforced folder boundary.

Private use, not public registration

The application is for its operator only. This site has no sign-in form, financial uploads, payment facilities or public account registration.
